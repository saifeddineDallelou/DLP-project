# libmagic bindings, split by platform. python-magic-bin ships the Windows
# DLL; on Linux and macOS the library comes from the OS (libmagic1 /
# libmagic), so the pure binding is the right package. Without the split this
# file could not be installed anywhere but Windows -- which is backwards for a
# stateless microservice that would normally be deployed on Linux.
#
# engine.py already treats magic as optional (see _MAGIC_AVAILABLE), so a host
# missing the system library degrades to "no file-type detection" rather than
# failing to start.
